# Project Name : Linear Machine Learning Model (Regression Models) Analysis System 

# Project Description:
 This Project aims to build a system to analyze and compare various Linear models (Linear, Ridge, Lasso, ElasticNet) on different datasets with support of preprocessing , feature selection, hyper parameter tuning and visualization.

# This project include the following things :
  1.Regression only
  2.Linear models:
    *Linear Regression
    *Ridge
    *Lasso
    *Elastic Net
  3.Dataset upload + default dataset
  4.Feature selection (manual + automatic)
  5.Cross-validation
  6.Hyperparameter tuning (alpha, l1_ratio)
  7.Visualizations
  8.Real-time prediction
  9.Streamlit UI


The User flow of the project is :
    1. The User select a dataset , default or other 
    2. User selects target column and features
    3. User chooses models and adjusts the hyperparameters
    4. User train the model and 
    5. Gets: Metrics, Graphs, features
    6. User gets the prediction
